# Contributing

Contributions are welcome. For larger changes, open an issue first so the scope
and expected behavior are clear.

## Development

- Install Bun 1.3.4 and Node.js 24 or later.
- Run `bun install`, then `bun run dev`.
- Run `bun run ci` before opening a pull request. It runs formatting and lint
  checks, type checking, tests, and a production build.

Do not add translation files from an unverified source or include private user
data in an issue or pull request. Translation text has separate rights from the
application code; see `THIRD_PARTY_NOTICES.md` and the README's Data,
attribution, and license section.
